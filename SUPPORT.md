# Support

## Get help

1. Read the [README](README.md), especially the prerequisites, compatibility, security, and troubleshooting sections.
2. Search [existing issues](https://github.com/eddielin0926/localbox/issues) for the same behavior.
3. If the question remains, open a [question](https://github.com/eddielin0926/localbox/issues/new?template=question.yml) and include your Localbox, Node.js, Docker, and operating-system versions.

For reproducible defects, use the [bug report form](https://github.com/eddielin0926/localbox/issues/new?template=bug-report.yml). For proposed behavior, use the [feature request form](https://github.com/eddielin0926/localbox/issues/new?template=feature-request.yml).

Community support is provided on a best-effort basis. There is no guaranteed response time.

## Scope

Localbox can help with its own API, Docker integration, and documented Vercel compatibility. For general Docker support, use the [Docker documentation](https://docs.docker.com/). For the hosted Vercel Sandbox service or APIs Localbox does not implement, use [Vercel support](https://vercel.com/help).

## Security

Do not report vulnerabilities through a public issue. Follow the private reporting instructions in [SECURITY.md](SECURITY.md).
